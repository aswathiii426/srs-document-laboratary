# Software Requirements Specification

## Project Title
Student Management System

## Laboratory Activity
Preparation of Software Requirements Specification (SRS) Document

## Objective
The objective of this laboratory activity is to analyze the
requirements of a software system and prepare a structured
Software Requirements Specification document.

## Problem Statement
The Student Management System is proposed to manage student
information such as student details, course information,
attendance, marks and other academic information in an
organized manner.

## Project Scope
The system will provide facilities for storing, managing,
updating and retrieving student-related information.

## Expected Outcome
A complete Software Requirements Specification document
containing functional requirements, non-functional
requirements, system requirements, constraints and other
necessary specifications.

Work in progress.# srs-document-laboratary
